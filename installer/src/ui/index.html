Welcome to JRoute

JRoute is a self-hosted reverse proxy for JanitorAI — one OpenAI-compatible endpoint in front of your own LLM providers.

This wizard will download a Node.js runtime, fetch and build JRoute, and run it locally. An internet connection is required (it clones/builds during setup).
